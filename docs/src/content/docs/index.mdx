## What ReplicaDB does

ReplicaDB is an open-source tool for moving data in batches. For example, it
can read orders from an operational PostgreSQL database and copy them into a
reporting table. The source connector reads the selected rows and the sink
connector writes them to the destination. ReplicaDB can split large reads
across parallel tasks when the connectors support it.

The same engine works with relational databases, document stores, files,
object storage and streams. It reads through the source connector without
requiring source agents or database triggers. Incremental runs select rows by
a filter or watermark and do not read the database's transaction log.
