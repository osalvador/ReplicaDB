ReplicaDB moves data in parallel between relational, document, file,
object-storage, and stream systems without requiring source agents or database
triggers. The standalone CLI and managed server reuse the same replication core;
choose between them based on ownership, state, and repeatability. Read the
[product comparison](/ReplicaDB/getting-started/choose-cli-or-server/) if you
need to compare the two operating models first.
