ReplicaDB provides two operating paths over the same replication core. Run a
direct transfer from a terminal, or operate durable authenticated jobs from a
shared control plane. The choice is about ownership, state, and repeatability,
not a different data-movement engine. Read the
[product comparison](/ReplicaDB/getting-started/choose-cli-or-server/) if you
need to compare the two operating models first.
