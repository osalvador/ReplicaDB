# Connector support

This matrix is generated from the maintained capability source and checked
against the Java manager registry. Roles describe whether a manager can be a
source or sink; source and sink modes are listed separately so a readable
source mode is never presented as a sink guarantee. Connector pages add
connection, driver, query, job-count, type, staging, and security details.

<SupportMatrix
  caption="ReplicaDB connector capability matrix"
  rows={capabilities.map((connector) => ({
    name: connector.displayName,
    sourceModes: connector.sourceModes,
    sinkModes: connector.sinkModes,
    staging: connector.staging ? 'Supported where the mode requires it' : 'Not provided',
    caveat: connector.caveats[0]
  }))}
/>
