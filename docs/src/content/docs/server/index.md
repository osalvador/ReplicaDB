# Managed server guide

The managed server adds authenticated durable operation around the ReplicaDB
replication core. It provides datasource profiles, jobs, schedules, run
history, diagnostics, permissions, users, and audit events.

## Follow the workflow

- [Install and choose a server profile](/ReplicaDB/server/installation/).
- [Sign in and manage your profile](/ReplicaDB/server/sign-in-and-profile/).
- [Read the dashboard](/ReplicaDB/server/dashboard/).
- [Create and edit datasources](/ReplicaDB/server/datasources/).
- [Create and operate jobs](/ReplicaDB/server/jobs/).
- [Schedule recurring runs](/ReplicaDB/server/schedules/).
- [Inspect runs and diagnostics](/ReplicaDB/server/runs-and-diagnostics/).
- [Manage users](/ReplicaDB/server/users/).
- [Apply resource permissions](/ReplicaDB/server/permissions/).
- [Review audit events](/ReplicaDB/server/audit/).

The frontend is a usability layer. Backend authorization remains authoritative
for every resource and action.
